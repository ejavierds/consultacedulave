Política de Privacidad

Esta aplicación no almacena, comparte ni comercializa los datos ingresados en este formulario (Nacionalidad y Cédula).

Las consultas se realizan a través de un proxy serverless directamente hacia el proveedor de la API de origen. Las credenciales de acceso se mantienen cifradas en nuestro servidor.

Al utilizar el servicio, acepta que sus datos sean enviados temporalmente a través de nuestra infraestructura solo con el fin de consultar la fuente original.
